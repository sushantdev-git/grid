MODULE 01 // AD-HOC TOPOLOGY

The Multi-Hop Mesh: How Packets Flow Without Towers

In Grid, every participant acts as both client and router. Messages propagate through neighbor-to-neighbor Bluetooth Low Energy flooding. Controlled TTL attenuation prevents broadcast storms, while LRU deduplication guarantees packets are processed exactly once.

MODULE 02 // ZERO-TRUST ENCRYPTION

How Strangers Authenticate Without Central Identity Servers

Signal and WhatsApp rely on centralized phone directory servers to exchange public keys. Grid uses the military-grade Noise_XX mutual handshake protocol. Neither party needs prior knowledge of each other, yet both authenticate securely with forward secrecy.

MODULE 03 // OFF-GRID ACOUSTICS

Squeezing High-Fidelity Voice Through a 469-Byte Pipe

Bluetooth LE maximum transmission units (MTU) are restricted to 469 bytes. Grid captures speech using the low-latency Opus voice codec, slices the bitstream into indexed binary fragments, and reconstructs the audio on the receiving end with out-of-order jitter buffering.

MODULE 04 // PHYSICAL SOVEREIGNTY

Instant Panic Zeroization: Zero Dialogs, Zero Traces

In hostile encounters or physical device seizure, confirmation dialogs like "Are you sure?" can lead to compromise. Grid implements instant memory zeroization—overwriting RAM buffers with random noise before zeroing all cryptographic identity keys.
